### Step 2.1: 加 write_message_with_fds

在 `framing.rs` 加（镜像 server framing.rs:216 的 sendmsg+ScmRights，全 safe nix）：

```rust
use nix::sys::socket::ControlMessage;
use nix::sys::socket::MsgFlags;
use nix::sys::socket::sendmsg;
use std::io::IoSlice;
use std::os::fd::AsRawFd;
use std::os::fd::RawFd;
```

```rust
/// 写一帧（header + payload）并经 SCM_RIGHTS 附带 `fds` 到 stream。
///
/// 用 `nix::sendmsg` + `ControlMessage::ScmRights`——**全 safe nix API，无 unsafe**
/// （收 fd 才需 `OwnedFd::from_raw_fd` unsafe；本函数只发不收）。fd 必须随首字节
/// 发出（vfio-user spec：所有 fd 跟首字节走），故单次 sendmsg 带 header+payload+cmsg。
pub(crate) fn write_message_with_fds(
    stream: &mut UnixStream,
    header: &Header,
    payload: &[u8],
    fds: &[RawFd],
) -> anyhow::Result<()> {
    let hdr_bytes = header.as_bytes();
    let iov = [IoSlice::new(hdr_bytes), IoSlice::new(payload)];
    let cmsgs = [ControlMessage::ScmRights(fds)];
    let sent = sendmsg::<()>(
        stream.as_raw_fd(),
        &iov,
        if fds.is_empty() { &[] } else { &cmsgs },
        MsgFlags::empty(),
        None,
    )
    .context("write_message_with_fds: sendmsg")?;
    // short-write 处理：fd 随首字节已发出；若 sendmsg 未写完 header+payload，补尾。
    let total = hdr_bytes.len() + payload.len();
    if sent < total {
        // 拼剩余字节用普通 write_all（fd 已随首字节发送，无需重发）。
        let mut all = Vec::with_capacity(total);
        all.extend_from_slice(hdr_bytes);
        all.extend_from_slice(payload);
        stream
            .write_all(&all[sent..])
            .context("write_message_with_fds: write_all tail")?;
    }
    stream.flush().context("write_message_with_fds: flush")?;
    Ok(())
}
```

注意：
- `header.as_bytes()` 需 `zerocopy::IntoBytes`（framing.rs 顶部 W1 已 `use zerocopy::IntoBytes;`）。
- `sendmsg::<()>` 的第 5 参数是 `Option<&SockaddrLike>` = `None`（UnixStream 已连接，无需 addr）。确认 nix 0.30 `sendmsg` 签名 `sendmsg<S>(fd, iov, cmsgs, flags, addr: Option<&S>)`——若签名不同按实调整（grep server framing.rs:262 的实际调用形态对齐）。
- short-write 分支保守处理（实际 header+payload 很小，单次 sendmsg 几乎必然写完；但对齐 server 的健壮性）。

### Step 2.2: framing roundtrip 单测（发 fd → 对端收到）

在 `framing.rs` 的 `#[cfg(test)] mod tests` 加（用 server framing 的 read_message 收 fd 验证——但 client crate 没有 server 的 read_message。改用 nix recvmsg 在测试里直接验，或更简单：发一个 fd（如 dup 一个 pipe/eventfd），对端用 `std::os::fd` 收。**最简**：socketpair 一端 write_message_with_fds 发一个 fd（dup /dev/null），另一端用 nix recvmsg 收，验证收到 1 个 fd + header/payload 正确）：

```rust
    #[test]
    fn write_with_fds_sends_one_fd() {
        use nix::sys::socket::{recvmsg, ControlMessageOwned, MsgFlags};
        use std::io::IoSliceMut;
        use std::os::fd::{AsRawFd, OwnedFd};
        use vfio_user_wire::proto::Command;

        let (mut a, b) = UnixStream::pair().unwrap();
        // 发一个真 fd：打开 /dev/null。
        let devnull = std::fs::File::open("/dev/null").unwrap();
        let payload = b"dma-map-payload".to_vec();
        let hdr = Header::command(3, Command::DmaMap, payload.len() as u32);
        write_message_with_fds(&mut a, &hdr, &payload, &[devnull.as_raw_fd()]).unwrap();

        // 对端用 recvmsg 收 header+payload + 1 个 fd。
        let mut buf = vec![0u8; HEADER_LEN + payload.len()];
        let mut iov = [IoSliceMut::new(&mut buf)];
        let mut cmsg = nix::cmsg_space!([RawFd; 4]);
        let msg = recvmsg::<()>(b.as_raw_fd(), &mut iov, Some(&mut cmsg), MsgFlags::empty()).unwrap();
        let mut got_fd = false;
        for c in msg.cmsgs().unwrap() {
            if let ControlMessageOwned::ScmRights(fds) = c {
                if let Some(&raw) = fds.first() {
                    // SAFETY-free：收下立即包 OwnedFd 自动 close。
                    // 注：本 crate deny(unsafe_code)，from_raw_fd 是 unsafe——
                    // 测试里改用计数验证，不实际持有 fd（见下）。
                    let _ = raw;
                    got_fd = true;
                }
            }
        }
        assert!(got_fd, "对端应收到 1 个 SCM_RIGHTS fd");
        assert_eq!(&buf[HEADER_LEN..], payload.as_slice());
    }
```

**注意 unsafe 陷阱**：测试里收 fd 后若 `OwnedFd::from_raw_fd(raw)` 是 unsafe，会破 `deny(unsafe_code)`。上面只 `let _ = raw; got_fd = true;`（不持有 fd，仅验证收到）——但这样收来的 raw fd 会泄漏（不 close）。测试进程短命可接受，但更干净的做法：**本 framing roundtrip 测改为只验证 send 不报错 + 对端能读到正确 header/payload 字节数**（fd 是否真传到由 Stage 4 的 loopback DMA 测端到端验证——server 真 mmap 成功即证 fd 传达）。**推荐删掉 cmsg 收 fd 部分**，只留：

```rust
    #[test]
    fn write_with_fds_sends_header_and_payload() {
        use vfio_user_wire::proto::Command;
        let (mut a, mut b) = UnixStream::pair().unwrap();
        let devnull = std::fs::File::open("/dev/null").unwrap();
        let payload = b"dma-map-payload".to_vec();
        let hdr = Header::command(3, Command::DmaMap, payload.len() as u32);
        write_message_with_fds(&mut a, &hdr, &payload, &[devnull.as_raw_fd()]).unwrap();
        // 用 W1 纯 read_message 读回 header+payload（fd 在 ancillary，纯 read 忽略它，
        // 但 header+payload 字节流不受影响）。
        let got = read_message(&mut b).unwrap();
        let msg_id = got.header.msg_id;
        assert_eq!(msg_id, 3);
        assert_eq!(got.payload, payload);
    }
```

**采用此版本**（不收 fd，避开 unsafe；fd 真正传达由 Stage 4 loopback DMA 端到端证）。`read_message`（W1 纯 read_exact）忽略 ancillary fd，只读字节流——header+payload 正确即证 send 格式对。

### Step 3.2: dma_map / dma_unmap / dma_unmap_all

在 `impl VfioUserClient` 加：

```rust
    /// DMA_MAP：把 `fd` 指向的内存（从 `fd_offset` 起 `size` 字节）映射到 IOVA
    /// `[gpa, gpa+size)`，server mmap 它做零拷贝 DMA。`flags` = READABLE|WRITEABLE。
    ///
    /// fd 经 SCM_RIGHTS 单独传（vfio-user：单 region 单 fd）。reply 是 header-only OK。
    pub fn dma_map(
        &mut self,
        gpa: u64,
        size: u64,
        flags: u32,
        fd: BorrowedFd<'_>,
        fd_offset: u64,
    ) -> anyhow::Result<()> {
        let req = DmaMapPayload {
            argsz: core::mem::size_of::<DmaMapPayload>() as u32,
            flags,
            offset: fd_offset,
            addr: gpa,
            size,
        };
        let msg_id = self.alloc_msg_id();
        let hdr = Header::command(msg_id, Command::DmaMap, core::mem::size_of::<DmaMapPayload>() as u32);
        write_message_with_fds(&mut self.stream, &hdr, req.as_bytes(), &[fd.as_raw_fd()])
            .context("send DMA_MAP")?;
        let reply = read_message(&mut self.stream).context("recv DMA_MAP reply")?;
        Self::expect_reply(&reply, msg_id, Command::DmaMap)?;
        Ok(())
    }

    /// DMA_UNMAP：精确撤销 `[gpa, gpa+size)` 的映射（含其 mmap）。
    pub fn dma_unmap(&mut self, gpa: u64, size: u64) -> anyhow::Result<()> {
        let req = DmaUnmapPayload {
            argsz: core::mem::size_of::<DmaUnmapPayload>() as u32,
            flags: 0,
            addr: gpa,
            size,
        };
        self.dma_unmap_inner(&req)
    }

    /// DMA_UNMAP（UNMAP_ALL flag）：撤销所有映射。
    pub fn dma_unmap_all(&mut self) -> anyhow::Result<()> {
        let req = DmaUnmapPayload {
            argsz: core::mem::size_of::<DmaUnmapPayload>() as u32,
            flags: dma_unmap_flags::UNMAP_ALL,
            addr: 0,
            size: 0,
        };
        self.dma_unmap_inner(&req)
    }

    /// DMA_UNMAP 公共发送路径（无 fd，纯 write）。reply echo `DmaUnmapPayload`。
    fn dma_unmap_inner(&mut self, req: &DmaUnmapPayload) -> anyhow::Result<()> {
        let reply = self.request(Command::DmaUnmap, req)?;
        // reply echo 整个 DmaUnmapPayload；expect_reply 已在 request 内做帧校验。
        let _ = reply;
        Ok(())
    }
```

注意：

- `dma_map` 不用 `request`（因要带 fd），手写 write_message_with_fds + read + expect_reply。

## Stage 4 — loopback DMA 零拷贝集成测

**Files:** `vfio_user_device/tests/loopback_dma.rs`

### Step 4.1: 写 loopback_dma.rs

设计（选项 A，零拷贝可观测）：
- tempfile 当 "guest RAM" backing file（set_len + client `FileExt::write_at` 写 marker，避开 client 侧 mmap/unsafe）。
- `DmaTriggerDev`（照搬 session.rs:1586 DoorbellDev）：doorbell offset → `ctx.dma_read(gpa_src, 8)`；`on_dma_complete(ctx, ...)` → 存 data（共享 handle）+ `ctx.dma_write(gpa_dst, data)` 回写。
- client：dma_map(fd) → write_at marker @ gpa_src → doorbell region_write → 收 region_write reply（cmd=RegionWrite **非 DmaRead** = 零拷贝反证）→ read_at @ gpa_dst 验 server dma_write 落地 + 共享 handle 验 dma_read 拿到 marker。

```rust
// Copyright (c) Microsoft Corporation.
// Licensed under the MIT License.

//! W3 loopback 集成测：client DMA_MAP fd → server mmap 零拷贝。
//! DmaTriggerDev doorbell → ctx.dma_read/dma_write 命中 mmap（wire 上无
//! DMA_READ/WRITE command = 零拷贝反证）+ 字节匹配。socketpair + tempfile，
//! Linux 直跑，无需 VTL。对标 POC-1。

use pcie_device_core::BarKind;
use pcie_device_core::BarLayout;
use pcie_device_core::DeviceCtx;
use pcie_device_core::DeviceDescribe;
use pcie_device_core::PcieDevice;
use std::os::fd::AsFd;
use std::os::unix::fs::FileExt;
use std::os::unix::net::UnixStream;
use std::sync::Arc;
use std::sync::Mutex;
use std::thread;
use vfio_user_device::VfioUserClient;

const GPA_SRC: u64 = 0x100; // dma_read 源
const GPA_DST: u64 = 0x200; // dma_write 目标
const MARKER: [u8; 8] = *b"W3-DMAOK";

/// doorbell → dma_read(GPA_SRC) → on_dma_complete 存数据 + dma_write(GPA_DST,数据)。
struct DmaTriggerDev {
    /// on_dma_complete 拿到的 (ok, data)，测试 join 后读。
    read_back: Arc<Mutex<Option<(bool, Vec<u8>)>>>,
}
impl PcieDevice for DmaTriggerDev {
    fn describe(&self) -> DeviceDescribe {
        DeviceDescribe {
            vendor_id: 0x1234,
            device_id: 0x5678,
            class_code: 0x01_08_02,
            revision: 1,
            subsystem_vendor: 0,
            subsystem_device: 0,
            bars: vec![BarLayout {
                index: 0,
                size: 8192,
                kind: BarKind::Mmio32,
                prefetchable: false,
            }],
            msix_count: 1,
            capabilities: vec![],
            cfg_write_side_effect_offsets: vec![],
        }
    }
    fn mmio_read(&mut self, _bar: u32, _offset: u64, _size: u32) -> u64 {
        0
    }
    fn mmio_write(&mut self, ctx: &mut DeviceCtx<'_>, _bar: u32, offset: u64, _size: u32, _value: u64) {
        // doorbell @ 0x1000 → dma_read GPA_SRC 8 字节（命中 mmap 零拷贝）。
        if offset == 0x1000 {
            let _tok = ctx.dma_read(GPA_SRC, MARKER.len() as u32);
        }
    }
    fn on_dma_complete(&mut self, ctx: &mut DeviceCtx<'_>, _token: u64, ok: bool, data: Vec<u8>) {
        *self.read_back.lock().unwrap() = Some((ok, data.clone()));
        // 把读到的数据零拷贝写回 GPA_DST（验证 dma_write 命中 mmap）。
        ctx.dma_write(GPA_DST, data);
    }
}

fn spawn_server(
    server_end: UnixStream,
    read_back: Arc<Mutex<Option<(bool, Vec<u8>)>>>,
) -> thread::JoinHandle<anyhow::Result<()>> {
    thread::spawn(move || -> anyhow::Result<()> {
        let mut s = server_end;
        let neg = vfio_user_transport::server_handshake(&mut s)?;
        let mut sess = vfio_user_transport::VfioUserSession::new(s, neg);
        let mut dev = DmaTriggerDev { read_back };
        while sess.pump_one(&mut dev)? {}
        Ok(())
    })
}

#[test]
fn loopback_dma_map_zero_copy() {
    // "guest RAM" backing file：4 KiB，写 marker @ GPA_SRC。
    let ram = tempfile::tempfile().unwrap();
    ram.set_len(4096).unwrap();
    ram.write_at(&MARKER, GPA_SRC).unwrap();

    let (server_end, client_end) = UnixStream::pair().unwrap();
    let read_back = Arc::new(Mutex::new(None));
    let server = spawn_server(server_end, read_back.clone());

    let mut client = VfioUserClient::from_stream(client_end);
    client.handshake().expect("handshake");

    // 1. DMA_MAP 整段 [0, 4096) RW，fd = ram，fd_offset=0。
    client
        .dma_map(
            0,
            4096,
            // READABLE | WRITEABLE
            0x1 | 0x2,
            ram.as_fd(),
            0,
        )
        .expect("dma_map");

    // 2. doorbell：BAR0 REGION_WRITE @ 0x1000 → server device dma_read(GPA_SRC)
    //    命中 mmap 零拷贝。**若零拷贝失败**（无 fd/mmap miss），server 会发
    //    server-initiated DMA_READ command 回打 client，则下面 region_write 的
    //    reply 读到的会是 DMA_READ(cmd=11) 而非 REGION_WRITE(cmd=10)，expect_reply
    //    cmd 校验失败 → 测试挂。故 region_write 成功本身 = 零拷贝反证。
    client
        .region_write(0, 0x1000, &1u32.to_le_bytes())
        .expect("doorbell region_write（成功即证 wire 上无 DMA_READ = 零拷贝命中）");

    // 3. 验 server dma_write 零拷贝落地：读 backing file @ GPA_DST 应见 marker。
    let mut dst = [0u8; 8];
    ram.read_at(&mut dst, GPA_DST).expect("read_at GPA_DST");
    assert_eq!(dst, MARKER, "server dma_write 应零拷贝写 marker 到 GPA_DST");

    // 4. dma_unmap 撤销。
    client.dma_unmap(0, 4096).expect("dma_unmap");

    drop(client);
    server.join().unwrap().expect("server loop");

    // 5. 验 dma_read 拿到的字节 == marker（零拷贝读命中正确数据）。
    let rb = read_back.lock().unwrap();
    let (ok, data) = rb.as_ref().expect("on_dma_complete 应被调用");
    assert!(*ok, "dma_read 应成功");
    assert_eq!(data.as_slice(), &MARKER, "dma_read 零拷贝拿到 marker");
}
```

注意：
- `ram.as_fd()` 返回 `BorrowedFd<'_>`（std `AsFd`）；dma_map 签名收 `BorrowedFd`。
- `FileExt::{write_at, read_at}`（`std::os::unix::fs::FileExt`）—— pwrite/pread，无 mmap、无 unsafe。MAP_SHARED 与 file I/O 在 tmpfs 上 coherent（server mmap 写 → client read_at 见）。
- doorbell offset 0x1000 + DMA_MAP 覆盖 [0,4096) 含 GPA_SRC=0x100 / GPA_DST=0x200。
- **时序**：handle_region_write → mmio_write → ctx.dma_read（mmap hit 同步 queue completion）→ session 排空 pending_completions → on_dma_complete（ctx.dma_write mmap hit）→ 发 REGION_WRITE reply。全在一次 pump_one 内同步完成（DoorbellDev 测 session.rs:1644 证 on_dma_complete 在 doorbell pump 内被投递）。
- 若 `on_dma_complete` 的 ctx.dma_write 时序导致 GPA_DST 写在 region_write reply 之后才可见——client 在收到 region_write reply 后才 read_at，此时 pump_one 已返回（completion 已处理），故可见。若实测时序问题，把 read_at 移到 dma_unmap 之后（更晚）。
